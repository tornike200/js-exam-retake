# გამოცდის ინსტრუქცია

1. სწავლის შედეგისთვის დასადასრურებლად გამოიყენეთ შეაბამისი საქაღალდე. თითოეულ საქაღალდეს აქვს `index.html` და `script.js` ფაილი, საჭიროების შემთხვევაში შექმენით `style.css`.

2. გამოცდის დასრულების შემდეგ შეინახეთ საბოლოო ვერსია გითზე, (`Git add .` , `git commit -m "დასრულებული გამოცდა"` , `git push`)

---

## სწავლის შედეგი 1

1.  გამოაცხადეთ ფუნქცია `calculateAverage` და ასევე სამი ცვლადი: `score1`, `score2`, `score3`
2.  მიანიჭეთ ამ ცვლადებს რიცხვითი მნიშვნელობები (მაგალითად: 85, 90, 78);
3.  არითმეტიკული ოპერატორების გამოყენებით გამოთვალეთ ამ სამი ქულის საშუალო არითმეტიკული;
4.  გამოტანის ოპერატორების მეშვეობით მიღებული შედეგი (საშუალო ქულა) დაბეჭდეთ კონსოლში.

---

## სწავლის შედეგი 2: If/Else, ციკლები, ღილაკები და Input

1. შექმენით ცვლადები: `temperature` და შეინახეთ მასში რიცხვითი მნიშვნელობა. პირობითი ოპერატორის მეშვებით შეამოწმეთ, თუ `temperature` მეტია 30-ზე კონსოლში გამოიტანეთ "ცხელი ამინდია", თუ 15-დან 30-მდეა გამოიტანეთ "ზომიერი ამინდია", თუ 15-ზე ნაკლებია გამოიტანეთ "ცივი ამინდია".
2. სასურველი ციკლის გამოყენებით კონსოლში გამოიტანეთ ყველა კენტი რიცხვი 1 დან 25 მდე.
3. HTML-ში შექმენით ღილაკი. როდესაც დააჭერთ ღილაკს, გვერდის ფონის ფერი შეიცვალოს სხვა ფერით.
4. HTML-ში შექმენით input ველი და ღილაკი. ღილაკზე დაჭერისას, ინფუთში ჩაწერილი რიცხვი გაამრავლეთ 2-ზე და შედეგი გამოიტანეთ ღილაკის ქვევით.

## სწავლის შედეგი 3: მასივები (Arrays)

1. გაქვთ შემდეგი ქალაქები:  
   `თბილისი`, `ბათუმი`, `ქუთაისი`, `რუსთავი`, `გორი`, `ზუგდიდი`, `ფოთი`, `ახალციხე`, `ტელავი`, `ოზურგეთი`, `მცხეთა`.

   გამოიყენეთ `for` ციკლი და შექმენით ახალი მასივი, სადაც იქნება მხოლოდ ის ქალაქები, რომელთა სიგრძე 6 ზე ნაკლებია.

2. წაშალეთ ახალი მასივის პირველი ელემენტი და დაამატეთ ახალი ქალაქი მასივის ბოლოში.

3. მოცემულია შემდეგი მასივი:

```javascript
arrOfPrices = [25, 150, 80, 200, 50, 95, 300, 45, 120];
```

`filter()` მეთოდის გამოყენებით შექმენით ახალი მასივი, სადაც იქნება მხოლოდ ის ფასები, რომლებიც ნაკლებია 100-ზე.

4. მოცემულია ორი მასივი:

```javascript
arr1 = [3, 8, 1, 12, 5];
arr2 = [7, 2, 9, 4, 11];
```

გააერთიანეთ ეს ორი მასივი და მიიღეთ ახალი მასივი, დაალაგეთ ახალი მასივი ზრდადობით და შედეგი გამოიტანეთ კონსოლში.

## სწავლის შედეგი 4: Date, String, Storage, Time, alert, Event Listeners

1. დროისა და თარიღის ფუნქციის გამოყენებით, მიიღეთ დღევანდელი დღე და დაბეჭდეთ კონსოლში მიმდინარე საათი, წუთი და წამი;

2. მოცემულია ცვლადი: text = `JavaScript Programming`. ჩაშენებული ფუნქციების დახმარებით გადაიყვანეთ სტრიქონი დაბალ რეგისტრში და დათვალეთ რამდენი სიმბოლოა მასში;

3. შექმენით ორი ინფუთი (სახელი და გვარი) და ღილაკი. ღილაკზე დაჭერისას შეინახეთ ლოკალურ საცავში ორივე ინფუთში ჩაწერილი ტექსტი. გვერდის გადატვირთვისას კონსოლში გამოიტანეთ ლოკალურ საცავში შენახული ტექსტები.

4. შექმენით ღილაკი, ღილაკზე დაჭერისას confirm ის დახმარებით გამოაჩინეთ შეტყობინება "დარწმუნებული ხართ?". თუ მომხმარებელმა დააჭირა OK, კონსოლში გამოიტანეთ "დადასტურებულია".

5. ტაიმერის ფუნქციის გამოყენებით კონსოლში ყოველ 2 წამში დაბეჭდეთ "Timeout executed" ხუთჯერ.

## სწავლის შედეგი 5: HTML ელემენტების შეცვლა

1. გამოიყენეთ `getElementById()`, `querySelector()` ან `querySelectorAll()` HTML ელემენტების საპოვნელად. თითოეული ელემენტი გამოიტანეთ კონსოლში.

2. შეცვალეთ ნაპოვნი ელემენტების სტილები. შეგიძლიათ შეცვალოთ:
   - ტექსტის ფერი
   - საზღვრის სტილი (border)
   - padding ან margin
   - კლასის დამატება ან წაშლა

3. ჯავასკრიპტიდან შექმენით ახალი სია (ul) სამი ელემენტით (li) და დაამატეთ ის HTML გვერდზე.

4. ნაპოვ ელემენტებზე დაამატეთ event listener-ები (`mouseover`, `mouseout`, `input`, `dblclick`). როდესაც რომელიმე ივენთი ამოქმედდება, კონსოლში აჩვენეთ ივენთის შესაბამისი შეტყობინება.

```
https://jsonplaceholder.typicode.com/users
```

```javascript

  "name": "Giorgi Beridze",
  "username": "gberidze",

3. fetch() მეთოდის გამოყენებით მიიღეთ მონაცემები, გამოიყენეთ try/catch ბლოკი შეცდომების დასაჭერად.

```
https://jsonplaceholder.typicode.com/users?_limit=5
